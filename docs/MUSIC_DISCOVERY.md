# 音乐发现（1.19.1）

推荐围绕用户明确选择和实际收听形成的兴趣持续选歌。先用本地候选调整接下来的歌曲，再从后台扩充；探索限定在相近方向，避免为了多样性不断打断已形成的音乐口味。

## 音乐口味与兴趣池

- 推荐页「我的音乐口味」支持曲风、语言、氛围及版本类型多选。入口不强制弹出，可修改、清空或保存空选择。空选择继续从收听中学习，不删除历史和喜欢的歌。
- `MusicTasteStore` 在本机持久化主动选择；`MusicInterestPool` / `MusicInterestPoolStore` 保存候选及获得正反馈的歌曲。候选最多 320 首、保留 7 天；正反馈种子最多 80 首、保留 180 天。
- 池中仅保存曲目元数据和来源关系，不持久化临时播放地址，也不代表已缓存音频。重启后会检查过期时间并合并已有数据。
- 只有实际听够、喜欢、收藏等正反馈，以及用户已有收藏，才能提供扩展种子。未来待播歌曲、搜索结果和推荐曝光不会自动变成兴趣证据。
- 稳定偏好、当天收听和最近反馈共同决定兴趣分布，主动选择提供稳定方向。同一首歌按可识别歌名或 ID 归并，在各时间窗口内只取最强正向证据，避免重复点赞、里程碑和多份收藏不断放大权重。
- 同一设备的应用数据形成一套本地偏好；本版没有新增账号间隔离、云同步或群体协同推荐。

## 同类歌曲的手动辅助反馈

- 推荐页仅保留「歌曲反馈」和「我的音乐口味」两个轻入口，推荐状态和长说明不再常驻。反馈面板区分同类多推、同类少推和单曲不合口味。
- `MusicStyleFeedbackStore` 独立保存最多 200 首歌的最新选择；反向选择替换，重复点击同一选择可撤销。不会写入自动行为表、改写已选口味或将歌曲加入正反馈种子。
- 优先识别明确曲风，缺失时使用氛围或版本类型；不把整个语种、UP 主或音乐大区当作同类。无法识别时不记录猜测。
- 同类反馈只给候选分数增加有限调整，绝对值最高 0.75；30 天半衰期，180 天过期。不会绕过原有兴趣池准入、音乐筛选、去重或冷却规则，也不封禁整个曲风。
- 实际收听、点赞、收藏的学习权重和口味选择保持原逻辑；同类反馈重排后续推荐，当前歌曲继续播放。

## 实时反馈与选歌

- `PLAY_START` 只用于已听记录，不增加兴趣权重。实际播放推进达到 30 秒、过半和九成时产生相应信号；暂停、拖动进度和恢复旧进度不累计成听歌时长。搜索和歌单中的实际收听同样参与学习。
- 推荐流中，实际听过后主动提前切歌才产生跳过反馈；加载失败或播放器报错不会自动当作不喜欢。快跳和普通提前切歌先作用于单曲冷却；明确「不合口味」进入可撤销的不喜欢记录。
- 多首不同歌曲的负反馈逐步降低同类优先级，不因为一首不喜欢就封掉整个曲风、语言或 UP 主。单曲冷却与近 14 天已听避重分别生效，不喜欢列表的排除也独立保留。
- 反馈先保存到本地，重新评价候选并调整尚未播放的队列；后台请求合并时再检查反馈版本和播放来源。喜欢或修改口味不会重启正在播放的歌曲；主动跳过及「不合口味」沿用切歌操作。
- 切歌优先使用已有候选和已预取的播放信息，后台继续补池。没有可用候选时仍需等待接口，严格筛选后仍为空则提示稍后再试，不循环塞回已听歌曲。
- 核心曲风和语言匹配优先；只少量探索邻近兴趣，不强制保留无关热门配额。连续同曲风不再被视为疲劳，UP 主差异仅在音乐匹配分数接近时帮助打散。

## 发现与过滤

- 搜索保留主要兴趣，轮换次要方向、搜索词和页码；围绕得到正反馈的歌曲轮换关联搜索。最多并发三个请求，单个失败仍保留其他结果。
- 搜索词和关联来源仅是较弱的方向证据，不能盖过候选本身明确冲突的曲风或语言标签。只有完全没有兴趣证据时才用音乐子区帮助冷启动。
- 初始推荐、续播、池内重排及推荐兜底统一做音乐筛选。使用真实分区、标题、标签和时长排除教程、杂谈、游戏、生活等视频；搜索来源名称本身不视为歌曲证据。
- 近 14 天的实际播放事件参与跨会话避重；明确歌名尽量合并同歌不同上传版本，同 BVID 的不同本地 ID 也会排除。单会话最多保留 800 个已播 ID。
- 长期反馈保留窗口为 180 天，按 45 天半衰期衰减；事件上限 6000 条。旧收藏作为稳定证据使用，不伪装成刚发生的点赞。

## 自动检查

```powershell
gradlew.bat :app:testDebugUnitTest :app:assembleRelease --offline
```

回归覆盖音乐筛选、口味与语言匹配、兴趣分布归一化、同歌重复证据、主动选择、负反馈冷却、相近探索上限、队列不足时的约束、池容量与过期、恢复合并、跨会话避重，以及暂停和拖动进度的收听信号。

## 人工验收建议

1. 保留旧数据覆盖安装，打开「我的音乐口味」，测试多选保存、清空保存和关闭不保存；重启后检查选择保留。
2. 连续播放推荐，喜欢或实际听够几首后检查待播方向；连续跳过和点「不合口味」，确认排除单曲且不会封掉整个曲风。
3. 从搜索和歌单完整收听歌曲，再回推荐观察偏好；切换到歌单时确认后台请求不会混入原队列。
4. 在已有候选时弱网切歌，检查使用本地候选及后台补池；候选耗尽时检查重试提示，不将元数据池误当作离线音频。
5. 用小屏和较大字体检查口味弹层可滚动、保存可点击，推荐台曲名和进度可滚动查看、播放主控保持可操作。

## 边界

歌曲发现仍依赖 B 站接口、分类、标题和标签，不是音频级识别。分类缺失、跨区投稿、同名不同歌及复杂版本标题可能误判；少于 70 秒、超过 7 分钟或未知时长的内容不自动推荐。严格过滤可能导致候选不足。本版没有新增版权曲库、大规模推荐模型或留存效果实测，不保证所有用户都会喜欢推荐结果。
