# Madus Mobile · 设计规范

> 定调：**干净得像印刷品，好用得像 Spotify，认得出是线稿手账风。**

## 参考结论（综合 agent 调研 + 常见优秀实践）

详见 `REFERENCES.md`。从 Spotify 骨架与简约黑白产品中抽取、并采用的点：

| 参考对象/模式 | 采用什么 |
|---------------|----------|
| Spotify | 底栏四入口、迷你播放条、点开全屏 Now Playing、列表左封面右文案 |
| Apple Music / Podcasts | 大留白、主播放按钮突出、次要控件线图标 |
| Retro / InnerTune / Vinyl | 曲库分区清晰；歌词以后作为播放页内状态，不单独占 Tab |
| 黑白 editorial / 线稿 | 细描边卡片、近直角、纸感底、线框封面占位 |
| 系统媒体通知（后续） | MediaSession，不造桌面悬浮歌词 |

**组件优先级（已落地骨架）：** SongRow / MiniPlayer / NowPlaying / SectionTitle / LineFrame / SearchField  

明确不抄进**默认简约**：霓虹渐变、粒子、重漫画分镜气泡墙、首页信息流过载。  
液态玻璃是可选第二套主题（`VisualTheme.LiquidGlass`），整页另排，不替换默认。

## 视觉

- **浅色**：纸色 `#F7F5F2`，墨色 `#111111`，弱字 `#7A7A7A`，细线同墨色/浅灰
- **深色**：炭黑底 + 近白字，仍无彩色强调（封面可彩色）
- **圆角**：2dp 近直角
- **阴影**：不用；分层靠描边与底色差
- **图标**：Outlined 线框
- **封面**：UI 黑白线框；真实封面图后续可彩色

## 布局（Spotify 骨架）

```
┌─────────────────────┐
│ 页面内容（大标题）   │
│ 横滑歌单 / 列表      │
│                     │
├─────────────────────┤
│ 迷你播放条（有曲时） │
├─────────────────────┤
│ 首页 搜索 曲库 我的  │
└─────────────────────┘
```

次级页：正在播放、登录音源。

## 特色（只保留少数）

1. 纸感底 + 细黑描边卡片  
2. 大标题字距略紧、印刷感  
3. 空状态/占位用线框音符，不堆插画  

## 文案语气

短、直接、不营销腔。错误提示说清「演示/未接入」，不吓人。
