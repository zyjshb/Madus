# 桌面 vs 手机：歌单 / 播放列表能力对照

> 双 agent 审计 + 当前手机端实现（2026-07）

## 图例

- ✅ 手机已有  
- 🟡 部分有 / 简化  
- ❌ 手机没有（桌面有）  
- — 桌面也没有或仅后端  

---

## 一、歌单系统

| 能力 | 桌面 | 手机 |
|------|------|------|
| 看 B 站收藏夹列表 | ✅ | ✅ 首页卡片 |
| 打开歌单详情列表 | ✅ | ✅ |
| 点单曲播放 | ✅ | ✅（现会跳播放页） |
| 播放全部 | ✅ | ✅（歌单详情按钮） |
| 网易云 / QQ 云歌单 | ✅ | ❌ 已砍音源 |
| 本地自建歌单 | ✅ | ❌ |
| 新建 / 重命名 / 删除歌单 | 🟡 仅本地新建 | ❌ |
| 加歌到歌单 | ✅ 收藏弹窗 | ❌ |
| 从歌单移除 | ❌ | ❌ |
| 歌单导入导出 | 🟡 B站→本地 | ❌ |
| 红心「我喜欢」云同步 | ✅ 网易 | ❌ 仅本地心形 UI 无列表 |
| 3D 歌单架 | ✅ | ❌ 不做（移动端） |

| 播放页进队列 | ✅ | ✅ |

## 三、播放交互

| 能力 | 桌面 | 手机 |
|------|------|------|
| 点歌进入「正在播放」 | 🟡 舞台即播放区，无路由 | ✅ 点歌跳 `NOW_PLAYING` |
| 迷你播放条 | ✅ | ✅（Tab 页） |
| 进度条拖动 | ✅ | ✅ |
| 搜索点播 | ✅ | ✅ |
| 多 P / 合集展开 | ✅ B站 | 🟡 单 BV 多 P 可展开；收藏内未深展 |

---

## 四、建议手机 MVP 补齐顺序（若要对齐桌面核心）

1. **P0 体验（本轮已做）**：点歌→播放页；队列页可开；歌单可进详情+全部播放  
2. **P1**：队列删除单项、下一首插播、循环/随机按钮  
3. **P2**：本地歌单创建/加歌（DataStore）  
4. **P3**：红心持久化 +「我喜欢」列表
