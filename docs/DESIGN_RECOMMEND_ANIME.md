# 推荐 Tab · 汽水式电台 + 纯线稿

> 调研：汽水音乐推荐体验（2026-07）  
> **不做**：樱粉、荧光绿、二次元大色、贴纸  
> **坚持**：黑白线稿手账 + 清爽干净

## 用户定调

- 喜欢现有线稿，不要粉色/花色强调  
- 推荐页参考 **汽水音乐** 的做法  

## 汽水推荐核心（可抄）

| 点 | 汽水怎么做 | 我们怎么做 |
|----|------------|------------|
| 主路径 | 打开≈全屏推歌，不是歌单墙 | 底栏中间「推荐」= 全屏电台页 |
| 切歌 | 上下滑，像刷抖音 | 上滑下一首 / 下滑上一首（可再加大按钮） |
| 一屏一事 | 封面氛围 + 歌词 + 少控件 | 线框封面 + 歌名 + 少线标控件 |
| 打开即听 | 进推荐就播 | 进推荐自动连播（设置可关） |
| 减法 | 推荐页无 Banner、无运营墙 | 同样禁止杂乱入口 |
| 双上下文 | 推荐 / 最近播放 | 顶部分段：推荐流 \| 最近 |

**不抄**：荧光绿品牌色、短视频穿插、强社交评论一级、抖音关系链。

## 视觉（纯线稿）

- 纸色 / 墨色 / 灰阶 only  
- 1px 描边、近直角  
- 选中态：描边变粗或实心黑白反转，**不用彩色**  
- 封面可保留彩色或可选灰度（二选一后续定）  

## 底栏

```
首页 | 搜索 | 【推荐】 | 曲库 | 我的
```

中间「推荐」可轻微凸起；线稿图标；选中 = 反白/加粗线。

## 推荐页结构（线稿版汽水）

```
  推荐  |  最近
     （歌词 1–2 行，可选）
      ┌────────────┐
      │  线框封面   │
      └────────────┘
         歌名
         艺人
   ♡   ⏮  ⏯  ⏭   ≡队列
      ────●──────
   （可选）更熟 | 默认 | 更新鲜  ← 线框 chip
```

- **上滑** = 下一首  
- **双击封面** = 喜欢（可选）  
- 底部控件克制，不堆社交  

## 自动播放

- 进入推荐 Tab：默认 **开始/续播推荐流**（汽水心智）  
- 设置可关「进入推荐自动播放」  
- 若其他歌单正在播：不硬抢，或轻提示「切换到推荐」  

## 与首页分工

| 页 | 职责 |
|----|------|
| 首页 | 浏览、歌单、最近列表（Spotify 骨架） |
| 推荐 | 零决策竖滑电台（汽水骨架） |
| 搜索/曲库 | 主动找歌、资产 |

## MVP

1. 五 Tab，中间推荐  
2. 全屏推荐页 + 演示队列  
3. 上滑切歌 + 播放/暂停  
4. 进 Tab 自动播（可关）  
5. 纯线稿，无彩色强调  

详见 agent 调研摘要：汽水全屏竖滑、打开即听、极简三栏；我们只抄架构与手势，不抄夜店绿。
