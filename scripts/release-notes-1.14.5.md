**发布日期：** 2026-08-07

### 下载

### 新增 · 更新进度条
- 检查更新下载时显示**真实进度条** + 已下/总大小 + 百分比
- 状态更明确：正在连接 → 已开始下载 → 下载中 → 完成

- 下载进度在主线程刷新，不会“点了没反应”
- 手动跟随 GitHub 重定向，安装包大小更可靠

2. 或在 App 内：**我的 → 检查更新** → 点「更新到最新版」（需本机可访问 GitHub）
