## 音乐口味与实时推荐

- 推荐页新增「我的音乐口味」：选择喜欢的曲风、语言和氛围，随时修改或清空；也可以不选，直接随听学习。
- 音乐兴趣池保存在本机，重启后继续沿着已形成的口味找新歌；优先推荐合口味的候选，只少量探索相近曲风。
- 点开一首不再算喜欢。实际收听、喜欢和收藏影响后续推荐，同一首的重复反馈不会无限放大。
- 喜欢、听够、跳过或修改口味后，先调整已有待播歌曲，后台继续补充新歌，减少切歌等待网络。
- 推荐播放时可直接点「不合口味」。负反馈先冷却这首歌，同类逐步少推，不会因为几首不喜欢就封掉整个曲风或 UP 主。
- 保留音乐筛选、同歌版本去重与跨重启避重；待播候选不会自行成为兴趣依据，候选不足也不塞入全站视频。
- 小屏推荐页支持滚动查看封面和歌曲信息，播放主控保持固定；切换歌单后不再显示推荐调整提示。

67 项自动测试与 Release 构建通过；本版尚未完成真机实听验证。音乐筛选和同歌识别仍依赖 B 站元数据，实际匹配效果会受到曲库与标签质量影响。

### 使用

打开推荐页 →「我的音乐口味」→ 保存喜欢的方向。听到喜欢的歌就点爱心，不合口味可以跳过或点「不合口味」，接下来的推荐会继续调整。
