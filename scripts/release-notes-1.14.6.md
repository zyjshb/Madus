## Madus 1.14.6

**发布日期：** 2026-08-07

### 下载
- **Madus-1.14.6.apk**（正式版，无 debug）

### 针对「解析软件包失败」
1.14.2 等版本若应用内更新提示**解析软件包时出现问题**，多半是下载到了不完整包或非 APK 内容。本版：

- 下载后**强制校验**（大小 / ZIP 头 / AndroidManifest / dex）
- 坏包**不会**再送进系统安装器
- 安装包改存 `files` 目录（比 cache 更稳）
- 安装前给系统安装器显式授权 FileProvider
- 更新页增加 **重新下载** / **浏览器下载**

### 其它（继承 1.14.5）
- 真实进度条 + 已下/总大小 + 百分比

### 安装说明
1. 建议直接下载本页 **Madus-1.14.6.apk** 安装（最稳）  
2. 或 App 内：**我的 → 检查更新** → 更新到最新版  
3. 需允许「安装未知应用」
