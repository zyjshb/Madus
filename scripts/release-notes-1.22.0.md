## 推荐融合汽水音乐机制：反复收听、歌手反馈与听歌模式

- 同曲重播不再与「认真听一遍」等同：按 10 分钟 / 1 小时 / 1 天三档统计实际播放遍数，十分钟内反复听算喜欢，当天刷太多次才会降权。
- 「不喜欢」的作用域改为「这首歌 + 这位歌手」：同歌手其它歌一起后移，但不会封掉整个曲风或语种。
- 播放中按「上一首」比按「下一首」更接近否定，会让这首歌进入冷却。
- 新增听歌模式：熟悉 / 均衡 / 新鲜。熟悉更贴近已验证口味，新鲜给相邻曲风更多机会；默认均衡，不选时行为与上一版一致。
- 补队列时把「已经排好、还没播」的歌一起纳入重排，接缝处不再出现连续两首同曲风或同一 UP 主。
- 每日 5 点后首次启动会刷新一轮候选，跨夜听歌仍算前一天。
- 本次改动只影响推荐排序，口味选择、点赞、收藏、听歌记录全部保留。

推荐仍依赖 B 站元数据，不是声学分析；作者身份按 UP 主名字识别，改名或搬运号会让歌手维度的反馈失真。
