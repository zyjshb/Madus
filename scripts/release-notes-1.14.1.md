## 本阶段累计（1.13.x → 1.14.1）

### 新增

- 清屏短视频右侧 UP 头像（点进主页）
- 「我的」导入音乐接通外站歌单
- 设置：深色墨黑主题
- UP 主页资料 / 关注 / 投稿小说式翻页
- 队列整表 + 长按拖拽排序
- 推荐页 B 站识曲悬浮球

### 变更

- 外站导入恢复高召回匹配（1.14.0，撤销过严打分）
- 外站支持网易云 / QQ / 酷狗 / 酷我与多行「歌名 - 歌手」
- 哼唱：ACR humming 优先，候选可点再搜
- AI 搜去掉重复的「B站识曲」按钮
- UP 投稿与收藏夹同样：上一页 / 下一页（每页 40）

### 修复

- 上一首跳错方向与下标校准
- 识曲球切 Tab 记位置；上滑菜单左右滑手势

### 已知问题

- 部分 VIP / 冷门歌导入仍可能匹配到标题相近、内容不准的 B 站稿件
- 哼唱识别依赖 ACR / 讯飞配置与现场录音质量
