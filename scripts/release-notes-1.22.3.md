## 修复列表 key 重复导致的闪退

- 队列里同一首歌出现两次时，Compose 的 `LazyColumn` 会因 key 重复直接抛异常闪退。现在队列允许重复曲目，并且每一行有独立 key，拖拽排序不受影响。
- 曲库、最近播放、搜索、UP 空间、首页、不喜欢列表、歌单详情、缓存管理等列表，渲染前按曲目 id 去重，避免同样的 key 冲突闪退。
- 播放通知栏的「喜欢」写盘失败时只忽略本次操作，不再让整个播放服务崩掉。
- 崩溃处理更克制：协程里没接住的普通异常（网络、解析、存储）只写诊断日志，不再直接杀进程；OOM 这类 Error 仍交给系统处理，不会被静默吞掉。
- 1.22.2 的推荐融合（重复收听窗口、歌手反馈、熟悉/均衡/新鲜）与 Java 21 `addFirst` 崩溃修复全部保留。
- 顺手修掉 `build.gradle.kts` 里被错误编码写坏的中文注释，文件恢复成正常 UTF-8。

崩溃与内存心跳日志继续写到「下载/Madus/」，出问题时把最新的 `.log` 发来即可。
